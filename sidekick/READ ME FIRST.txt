נגן שיעורים / SHIUR PLAYER — COMPANION 1.1.0 (WINDOWS x64)

UPDATE BOTH PARTS
Close the OLD command-prompt companion once before updating. Extract the ENTIRE
new ZIP into a new folder. Keep the runtime folders beside Sidekick.exe.

1. Open Sidekick.exe. This version opens a normal app window, not a command prompt.
2. Use the Hebrew/English selector at the top if desired.
3. Click Choose recordings folder / בחירת תיקיית שיעורים. Select the folder
   containing your MP3/M4A/WAV recordings, not the folder containing Sidekick.exe.
   The app shows the full folder path and the number of recordings found.
4. If you add audio to that folder later, click Rescan folder / סריקה מחדש.
5. Click Copy code. Install the included sidekick-1.1.0.otzplugin as an UPDATE
   inside Otzaria. Restart Otzaria once, then open נגן שיעורים, paste the code and click Connect / חיבור.
6. Choose a recording or press Play. Play selects the first available recording
   if none is selected. Empty libraries show folder-selection instructions.

CLOSING WINDOWS
The app's X button or Hide and keep listening hides its setup window while audio
continues. Run Sidekick.exe again, use Open desktop app in the plugin, or press
Library / connection on the floating bar to reopen it. Exit player in the setup
window actually stops the app and saves progress. Closing Otzaria does not stop it.
There is no command window to keep open in this version.

LANGUAGE AND NAMES
The visible Hebrew name is נגן שיעורים. In English it is Shiur Player.
Sidekick remains only our nickname and the EXE filename. Both the desktop window
and the Otzaria controller offer Hebrew/English. Language, chosen folder, named
collections and saved per-recording positions are retained. A restart creates a
new connection code; remembered pairing is optional.

Recordings are referenced in their existing folder. Rescan does not copy, alter
or delete audio files. Update without uninstalling the plugin or deleting
%LOCALAPPDATA%\ShiurPlayerCompanion. Inside is a separate player with separate data.

TROUBLESHOOTING
If you still see a command window, the OLD EXE is running. Close it and launch
Sidekick.exe from this new extracted ZIP. Update the plugin from the SAME ZIP.
If zero recordings are shown, check the selected path and supported audio file
extensions, then rescan. Organizational collections are not folders on disk.
If an older companion is already using the local port, close it before starting
this version. The launcher reports missing files in a message box.

TESTING
Backend/browser tests cover rescanning, first-run folder selection, saved progress,
Hebrew/English persistence, pairing, playback commands and continued background
playback. Native setup-window and floating controls are tested with Windows API
mocks. The executable is verified as Windows GUI x64, and runtime files/licenses
are preserved. Real WAV/MP3 decoding passed on Linux with dummy audio output.
Actual Windows GUI rendering and physical audio output remain unverified here.

Python and reduced VLC are bundled; no separate installation is needed.
Runtime licenses/source links are included in THIRD-PARTY-NOTICES.txt.
There is no browser viewer or URL-opening control. Bundled Python is general
purpose; the program is not a device-wide browser/Internet lockdown tool.

After successful pairing, the plugin code form and native setup window hide automatically. Connection settings and Open desktop app reopen them. Audio continues.
